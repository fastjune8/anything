# 총 모델 만들기 (Blender → 게임)

Blender 로 만든 총을 게임에 넣기 위한 규칙이다. 규칙을 지키면 **파츠 부착, 정조준, 재장전 동작, 스킨이 자동으로 맞는다.**
다 만들면 **스튜디오의 총 모델**(`npm run dev` → http://localhost:3002/studio/ → 총 모델 **.glb 열기**, 또는 화면에 끌어다 놓기)에서 연다. 스튜디오가 규칙을 검사하고, 1인칭·정조준·파츠·스킨을 게임과 같은 화면으로 보여 준다.

> 처음이면 스튜디오 총 모델 목록의 **예시** 버튼을 눌러 보자. 아래 규칙대로 만든 모델이 어떻게 생겼는지 바로 볼 수 있다.

---

## 0. 한눈에 보는 체크리스트

- [ ] 단위 m, 배율 1.0 · 총구는 **+Y**, 위는 **+Z**, 좌우 가운데는 **x = 0**
- [ ] 월드 원점 = **방아쇠 바로 위, 총열 높이**
- [ ] 빈 물체(Empty) 4개 필수: `socket_ads`, `socket_muzzle`, `socket_hand_r`, `socket_hand_l` (+ 가능하면 `socket_optic`, `socket_grip`)
- [ ] 탄창은 따로: `part_mag` (원점 = 탄창 윗면) · 가늠자/가늠쇠: `part_irons_…`
- [ ] 재질 이름은 색 칸 6개 중에서: `body` `body2` `dark` `metal` `accent` `core` (텍스처 없이 단색)
- [ ] 삼각형 6,000개 이하 (최대 12,000) · 파일 300KB 이하 (최대 800KB)
- [ ] Ctrl+A → 모든 변환 적용 후 **glTF 2.0 (.glb)** 로 내보내기
- [ ] 스튜디오에서 "모두 통과" → id 입력 → **프로젝트에 저장** → 커밋

---

## 1. 스타일

참고 이미지처럼 **저폴리 + 평평한 면 + 단색** 스타일이다.

- 모서리는 둥글게 다듬지 말고 **한 번 깎은 면(Bevel 1단)** 정도로. 셰이딩은 **Shade Flat**.
- 텍스처를 쓰지 않는다. 색은 **재질(색 칸)** 로만 나눈다. 스킨이 색 칸의 색만 바꾸기 때문이다.
- 디테일은 실루엣이 읽히는 정도까지: 레일 홈, 조정간, 작은 표시 사각형. 볼트·나사 하나하나는 생략한다.
- 1인칭에서는 총의 **오른쪽 옆면과 윗면**이 가장 많이 보인다. 디테일은 그쪽에 쓴다.
- **실존 총을 모티브로 한 가상 총**: 실루엣과 부품 배치는 참고하되,
  - 실제 상표·로고·각인·모델명(M4, AK, Glock …)은 쓰지 않는다.
  - 비율을 바꾸거나 부품을 섞어(예: 불펍 몸통 + 다른 총의 총열 덮개) 한눈에 다른 총으로 보이게 한다.
  - 이 게임의 개성인 **스킬 코어**(빛나는 부분, `core` 색 칸)를 넣는다. 스킬이 준비되면 빛나는 용도로 쓸 예정이다.

## 2. Blender 준비

`tools/blender/frontier_gun_template.py` 를 쓰면 아래 설정과 빈 물체·재질을 한 번에 만들어 준다.
**Scripting 탭 → 열기 → 이 파일 → ▶ 실행.** (이미 있는 것은 건드리지 않으므로 여러 번 실행해도 된다)

직접 하려면:
- Scene 속성 → Units: **Metric**, Unit Scale **1.0**, Length 는 보기 편하게 Centimeters (내부 단위는 m 그대로)

### 방향과 원점

```
   위에서 본 모습 (Top, 숫자패드 7)          옆에서 본 모습 (Right, 숫자패드 3)

            +Y (총구)                         +Z (위)
              ▲                                 ▲
              │  ▐▌ ← 총구                       │   ▄▄▄▄▄▄▄▄▄▄▄▄▄
              │  ▐▌                              │  ▐████████▌═══════ → +Y (총구)
              │ ▐██▌                             ●──▀█▀───────────
              │ ▐██▌                            원점  █  (방아쇠 바로 위, 총열 높이)
   -X ────────●─────── +X (총의 오른쪽)               █ 손잡이
              │ ▐██▌
```

- **총구 = +Y**, **위 = +Z**, **총의 오른쪽 = +X**. (내보낼 때 게임 방향으로 자동 변환된다)
- **좌우 가운데 = x 0**. 총열·가늠자·총구가 x = 0 선 위에 있어야 한다.
- **원점 = 방아쇠 바로 위, 총열 중심 높이.** 1인칭에서 이 점을 기준으로 총이 놓이고 반동으로 흔들린다.

### 크기 (실제 총과 비슷하게)

| 종류 | 전체 길이 |
|---|---|
| 권총 | 0.18 ~ 0.25 m (0.35m 보다 짧으면 게임이 한 손 권총으로 다룬다) |
| 기관단총 | 0.50 ~ 0.70 m |
| 돌격소총 | 0.75 ~ 0.95 m |
| 산탄총 | 0.90 ~ 1.05 m |
| 경기관총 | 0.95 ~ 1.10 m |
| 저격소총 | 1.10 ~ 1.30 m |

스튜디오의 **크기 비교**로 지금 게임에 있는 총을 반투명으로 겹쳐 볼 수 있다.

## 3. 부착 지점 (빈 물체, Empty)

`Add → Empty → Plain Axes` 로 만들고 **이름을 정확히** 붙인다. 모양·크기는 상관없고 **위치만** 쓴다.

| 이름 | 필수 | 놓는 곳 | 게임에서 쓰는 곳 |
|---|---|---|---|
| `socket_ads` | ✔ | **가늠자 구멍 중심** (가늠쇠 끝과 같은 높이) | 정조준: 이 점과 총구 방향 선이 화면 가운데에 온다 |
| `socket_muzzle` | ✔ | 총구 끝 중심 | 총구 화염, 소음기·보정기 위치 |
| `socket_hand_r` | ✔ | 손잡이를 쥐는 오른손 중심 | 1인칭 오른팔 |
| `socket_hand_l` | ✔ | 총열 덮개를 받치는 왼손 (권총은 받치는 손) | 1인칭 왼팔 |
| `socket_optic` | | 레일 **윗면**, 조준경을 올릴 자리 | 조준경 파츠 (없으면 조준경을 못 단다) |
| `socket_grip` | | 총열 덮개 **아랫면**, 앞 손잡이 자리 | 앞 손잡이 파츠 |

- **정조준이 맞는지**는 스튜디오의 **정조준** 보기에서 확인한다. 빨간 점(조준점)에 가늠쇠 끝이 겹치면 된다.
- 눈과 가늠자 사이 거리는 소총 12cm, 권총 40cm (팔을 뻗으니까) 로 자동 설정된다.
  바꾸려면 `socket_ads` 의 **Object 속성 → Custom Properties** 에 `eye` (m 단위 숫자) 를 넣는다. (내보낼 때 Custom Properties 켜기)

## 4. 따로 움직이는 부품

물체 이름을 `part_…` 으로 붙인다. 물체 하나여도 되고, 빈 물체 아래 여러 메시를 자식으로 묶어도 된다.

| 이름 | 원점 (Set Origin) | 용도 |
|---|---|---|
| `part_mag` | **탄창 윗면** (몸통에 꽂히는 곳) | 재장전 때 빠졌다 들어감, 확장/신속 탄창 파츠는 아래로 늘어나거나 줄어듦 |
| `part_stock` | 몸통과 붙는 곳 | 경량/중량 개머리판 파츠가 크기를 바꿈 |
| `part_irons_front`, `part_irons_rear` … | 상관없음 | 조준경을 달면 숨김 (`part_irons` 로 시작하면 몇 개든) |
| `part_scope` | 상관없음 | 저격총의 붙박이 스코프 |
| `part_bolt` | 움직이는 축 | 노리쇠·슬라이드 (나중에 동작에 씀) |

원점 옮기기: 3D 커서를 원하는 곳에 두고 (Shift+우클릭) → **Object → Set Origin → Origin to 3D Cursor**.

## 5. 색 칸 (재질)

재질 이름이 곧 색 칸이다. `.001` 같은 꼬리는 무시한다 (`body.001` = `body`).

| 재질 이름 | 용도 | 예시 색 (참고 이미지) |
|---|---|---|
| `body` | 주 색 (가장 넓은 면) | `#e0a24a` 주황빛 노랑 |
| `body2` | 보조 색 (주 색보다 조금 어둡게: 아래 몸통, 손잡이, 개머리판) | `#c27f34` |
| `dark` | 어두운 부분 (레일, 총열 덮개, 탄창, 개머리판 패드) | `#262b36` |
| `metal` | 금속 (총열, 볼트) | `#3a3f47` |
| `accent` | 포인트 (작은 표시, 조정간) | `#d8382e` |
| `core` | **스킬 코어** (빛나는 부분, Emission 을 켠다) | `#3ad7ff` |

- **Base Color 만** 쓴다. Metallic·Roughness 는 바꿔도 되지만 **이미지 텍스처는 쓰지 않는다**.
- 6칸을 다 쓸 필요는 없다. 대신 이 밖의 이름은 스킨이 적용되지 않는다 (스튜디오가 알려 준다).
- 스튜디오의 **스킨**에서 사막·야간·숲·네온으로 바꿔 보며, 어느 색 칸으로 나눠야 스킨이 예쁘게 바뀌는지 확인한다.

## 6. 용량

| | 권장 | 최대 |
|---|---|---|
| 삼각형 수 | 6,000 | 12,000 |
| 파일 크기 | 300 KB | 800 KB |

- 원기둥(총열·총구)은 **8~12면**이면 충분하다.
- 안 보이는 면(부품끼리 맞닿은 안쪽)은 지운다.
- Decimate 로 줄이지 말자 (면이 지저분해진다). 처음부터 적은 면으로 만든다.

## 7. 내보내기

1. 모든 물체 선택 (A) → **Ctrl+A → All Transforms** (크기·회전 적용)
2. **File → Export → glTF 2.0**
   - Format: **glTF Binary (.glb)**
   - Include: 총만 있는 파일이면 그대로, 다른 게 섞여 있으면 **Selected Objects**. `socket_ads` 에 eye 를 넣었다면 **Custom Properties** 켜기
   - Transform: **+Y Up** 켜기 (기본값)
   - Data → Mesh: **Apply Modifiers** 켜기
   - Compression: **끄기** (게임이 압축 해제기를 쓰지 않는다)
   - Animation: 끄기
3. 파일 이름은 총 id 로: `vk12.glb` 처럼 **영문 소문자·숫자·_**

템플릿 스크립트의 `export_glb('/경로/vk12.glb')` 를 실행하면 위 설정으로 내보낸다.

## 8. 확인하고 저장하기

1. `npm run dev` → http://localhost:3002/studio/
2. .glb 를 화면에 끌어다 놓는다 (또는 총 모델 옆 **.glb 열기**)
3. 오른쪽 **규칙 검사**: ✕ 는 꼭 고친다 (저장이 잠긴다), ! 는 확인만.
4. 보기를 바꿔 가며 확인
   - **살펴보기**: 부착 지점이 제자리인지
   - **1인칭**: 게임에서 들었을 때 크기·위치가 괜찮은지
   - **정조준**: 빨간 점과 가늠쇠가 겹치는지
   - **파츠 달아 보기**: 조준경·소음기·앞 손잡이·탄창이 제자리에 붙는지
   - **스킨**: 색 칸이 잘 나뉘었는지
5. 위쪽에 총 id 를 넣고 **프로젝트에 저장** → `content/guns/<id>.glb` 가 생긴다.
6. 커밋해서 PR 로 올린다. Blender 원본(.blend)은 저장소 밖(또는 따로 정한 폴더)에 보관한다. 게임에는 .glb 만 들어간다.

> 지금은 스튜디오에서 확인하고 저장까지 된다. **저장한 모델을 실제 게임 총으로 쓰는 연결**(무기 데이터에 모델 지정, 다른 플레이어·무기고 벽에 표시)은 다음 작업이다. 그 전까지 게임은 지금의 코드로 만든 총을 쓴다.
