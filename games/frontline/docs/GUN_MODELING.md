# 총 모델 만들기 (Blender → 게임)

Blender 로 만든 총을 게임에 넣기 위한 규칙이다. 규칙을 지키면 **파츠 부착, 정조준, 재장전 동작, 스킨이 자동으로 맞는다.**
다 만들면 **스튜디오의 총 모델**(`npm run dev` → http://localhost:3002/studio/ → 총 모델 **.glb 열기**, 또는 화면에 끌어다 놓기)에서 연다. 스튜디오가 규칙을 검사하고, 1인칭·정조준·파츠·스킨을 게임과 같은 화면으로 보여 준다.

> 처음이면 스튜디오 총 모델 목록의 **예시** 버튼을 눌러 보자. 아래 규칙대로 만든 모델이 어떻게 생겼는지 바로 볼 수 있다.

---

## 0. 한눈에 보는 체크리스트

- [ ] 단위 m, 배율 1.0 · 총구는 **+Y**, 위는 **+Z**, 좌우 가운데는 **x = 0**
- [ ] 월드 원점 = **방아쇠 바로 위, 총열 높이**
- [ ] 빈 물체(Empty) 4개 필수: `socket_ads`, `socket_muzzle`, `socket_hand_r`, `socket_hand_l` (+ 가능하면 `socket_optic`, `socket_grip`)
- [ ] 탄창은 따로: `part_mag` (원점 = 탄창 윗면) · 가늠자/가늠쇠: `part_irons_…`
- [ ] 재질 이름은 색 칸 6개 중에서: `body` `body2` `dark` `metal` `accent` `core` (텍스처 없이 단색)
- [ ] 삼각형 6,000개 이하 (최대 12,000) · 파일 300KB 이하 (최대 800KB)
- [ ] Ctrl+A → 모든 변환 적용 후 **glTF 2.0 (.glb)** 로 내보내기
- [ ] 스튜디오에서 "모두 통과" → id 입력 → **프로젝트에 저장** → 커밋

## 1. 스타일

참고 이미지처럼 **저폴리 + 평평한 면 + 단색** 스타일이다.

- 모서리는 둥글게 다듬지 말고 **한 번 깎은 면(Bevel 1단)** 정도로. 셰이딩은 **Shade Flat**.
- 텍스처를 쓰지 않는다. 색은 **재질(색 칸)** 로만 나눈다. 스킨이 색 칸의 색만 바꾸기 때문이다.
- 디테일은 실루엣이 읽히는 정도까지: 레일 홈, 조정간, 작은 표시 사각형. 볼트·나사 하나하나는 생략한다.
- 1인칭에서는 총의 **오른쪽 옆면과 윗면**이 가장 많이 보인다. 디테일은 그쪽에 쓴다.
- **실존 총을 모티브로 한 가상 총**: 실루엣과 부품 배치는 참고하되,
  - 실제 상표·로고·각인·모델명(M4, AK, Glock …)은 쓰지 않는다.
  - 비율을 바꾸거나 부품을 섞어(예: 불펍 몸통 + 다른 총의 총열 덮개) 한눈에 다른 총으로 보이게 한다.
  - 이 게임의 개성인 **스킬 코어**(빛나는 부분, `core` 색 칸)를 넣는다. 스킬이 준비되면 빛나는 용도로 쓸 예정이다.

## 2. Blender 준비

`tools/blender/frontier_gun_template.py` 를 쓰면 아래 설정과 빈 물체·재질을 한 번에 만들어 준다.
**Scripting 탭 → 열기 → 이 파일 → ▶ 실행.** (이미 있는 것은 건드리지 않으므로 여러 번 실행해도 된다)

직접 하려면:
- Scene 속성 → Units: **Metric**, Unit Scale **1.0**, Length 는 보기 편하게 Centimeters (내부 단위는 m 그대로)

### 방향과 원점

```
   위에서 본 모습 (Top, 숫자패드 7)          옆에서 본 모습 (Right, 숫자패드 3)

            +Y (총구)                         +Z (위)
              ▲                                 ▲
              │  ▐▌ ← 총구                       │   ▄▄▄▄▄▄▄▄▄▄▄▄▄
              │  ▐▌                              │  ▐████████▌═══════ → +Y (총구)
              │ ▐██▌                             ●──▀█▀───────────
              │ ▐██▌                            원점  █  (방아쇠 바로 위, 총열 높이)
   -X ────────●─────── +X (총의 오른쪽)               █ 손잡이
              │ ▐██▌
```

- **총구 = +Y**, **위 = +Z**, **총의 오른쪽 = +X**. (내보낼 때 게임 방향으로 자동 변환된다)
- **좌우 가운데 = x 0**. 총열·가늠자·총구가 x = 0 선 위에 있어야 한다.
- **원점 = 방아쇠 바로 위, 총열 중심 높이.** 1인칭에서 이 점을 기준으로 총이 놓이고 반동으로 흔들린다.

### 크기 (실제 총과 비슷하게)

| 종류 | 전체 길이 |
|---|---|
| 권총 | 0.18 ~ 0.25 m (0.35m 보다 짧으면 게임이 한 손 권총으로 다룬다) |
| 기관단총 | 0.50 ~ 0.70 m |
| 돌격소총 | 0.75 ~ 0.95 m |
| 산탄총 | 0.90 ~ 1.05 m |
| 경기관총 | 0.95 ~ 1.10 m |
| 저격소총 | 1.10 ~ 1.30 m |

스튜디오의 **크기 비교**로 지금 게임에 있는 총을 반투명으로 겹쳐 볼 수 있다.

## 3. 부착 지점 (빈 물체, Empty)

`Add → Empty → Plain Axes` 로 만들고 **이름을 정확히** 붙인다. 모양·크기는 상관없고 **위치만** 쓴다.

| 이름 | 필수 | 놓는 곳 | 게임에서 쓰는 곳 |
|---|---|---|---|
| `socket_ads` | ✔ | **가늠자 구멍 중심** (가늠쇠 끝과 같은 높이) | 정조준: 이 점과 총구 방향 선이 화면 가운데에 온다 |
| `socket_muzzle` | ✔ | 총구 끝 중심 | 총구 화염, 소음기·보정기 위치 |
| `socket_hand_r` | ✔ | 손잡이를 쥐는 오른손 중심 | 1인칭 오른팔 |
| `socket_hand_l` | ✔ | 총열 덮개를 받치는 왼손 (권총은 받치는 손) | 1인칭 왼팔 |
| `socket_optic` | | 레일 **윗면**, 조준경을 올릴 자리 | 조준경 파츠 (없으면 조준경을 못 단다) |
| `socket_grip` | | 총열 덮개 **아랫면**, 앞 손잡이 자리 | 앞 손잡이 파츠 |

- **정조준이 맞는지**는 스튜디오의 **정조준** 보기에서 확인한다. 빨간 점(조준점)에 가늠쇠 끝이 겹치면 된다.
- 눈과 가늠자 사이 거리는 소총 12cm, 권총 40cm (팔을 뻗으니까) 로 자동 설정된다.
  바꾸려면 `socket_ads` 의 **Object 속성 → Custom Properties** 에 `eye` (m 단위 숫자) 를 넣는다. (내보낼 때 Custom Properties 켜기)

### 근접 무기 (칼 등)

`socket_tip` 이 있고 `socket_muzzle` 이 없으면 스튜디오가 **근접 무기**로 보고 근접 무기 규칙으로 검사한다.

| 이름 | 필수 | 위치 |
|---|---|---|
| `socket_hand_r` | ✓ | 오른손으로 쥐는 곳. **원점도 여기에** 둔다 |
| `socket_tip` | ✓ | 날 끝 (찌르는 곳 · 공격 판정). 손잡이보다 앞(+Y) |
| `socket_hand_l` | | 양손 무기일 때만 |

- 날 끝이 Blender 의 **+Y**(앞), 위가 +Z. 길이 1.6m 이하 권장
- 탄창·가늠자·조준경 규칙은 없다. 색 칸·용량 규칙은 총과 같다
- 등록하면 종류가 "근접 무기" 로 올라간다. 근접 공격(무기)이 게임에 생기면 그 무기에 연결한다

## 4. 따로 움직이는 부품

물체 이름을 `part_…` 으로 붙인다. 물체 하나여도 되고, 빈 물체 아래 여러 메시를 자식으로 묶어도 된다.

| 이름 | 원점 (Set Origin) | 용도 |
|---|---|---|
| `part_mag` | **탄창 윗면** (몸통에 꽂히는 곳) | 재장전 때 빠졌다 들어감, 확장/신속 탄창 파츠는 아래로 늘어나거나 줄어듦 |
| `part_stock` | 몸통과 붙는 곳 | 경량/중량 개머리판 파츠가 크기를 바꿈 |
| `part_irons_front`, `part_irons_rear` … | 상관없음 | 조준경을 달면 숨김 (`part_irons` 로 시작하면 몇 개든) |
| `part_scope` | 상관없음 | 저격총의 붙박이 스코프 |
| `part_bolt` | 움직이는 축 | 노리쇠·슬라이드 (나중에 동작에 씀) |

원점 옮기기: 3D 커서를 원하는 곳에 두고 (Shift+우클릭) → **Object → Set Origin → Origin to 3D Cursor**.

## 5. 색 칸 (재질)

재질 이름이 곧 색 칸이다. `.001` 같은 꼬리는 무시한다 (`body.001` = `body`).

| 재질 이름 | 용도 | 예시 색 (참고 이미지) |
|---|---|---|
| `body` | 주 색 (가장 넓은 면) | `#e0a24a` 주황빛 노랑 |
| `body2` | 보조 색 (주 색보다 조금 어둡게: 아래 몸통, 손잡이, 개머리판) | `#c27f34` |
| `dark` | 어두운 부분 (레일, 총열 덮개, 탄창, 개머리판 패드) | `#262b36` |
| `metal` | 금속 (총열, 볼트) | `#3a3f47` |
| `accent` | 포인트 (작은 표시, 조정간) | `#d8382e` |
| `core` | **스킬 코어** (빛나는 부분, Emission 을 켠다) | `#3ad7ff` |

- **Base Color 만** 쓴다. **이미지 텍스처는 쓰지 않는다**.
- **금속성·거칠기는 게임이 색 칸 이름으로 정한다** (`content/gunmaterials.json`, 스튜디오 모델 에디터 → "질감"). Blender 에서 넣은 Metallic·Roughness 값은 덮어쓰므로 신경 쓰지 않아도 된다. 모든 총이 같은 기준으로 보이고, 스킨을 바꿔도 금속은 금속, 폴리머는 폴리머로 보인다.

  | 색 칸 | 기본 성질 |
  |---|---|
  | `metal` | 가공된 강철 (금속 1, 거칠기 0.35) — 과열 스킬 때 달아오른다 |
  | `dark` | 폴리머·고무 (금속 0, 거칠기 0.82) |
  | `body` `body2` | 도장된 금속 (금속 0.25, 거칠기 0.5~0.58) |
  | `accent` | 도장 포인트 |
  | `core` | 스스로 빛남 — 차지 샷 충전·아드레날린 때 더 밝아진다 |
- 6칸을 다 쓸 필요는 없다. 대신 이 밖의 이름은 스킨이 적용되지 않는다 (스튜디오가 알려 준다).
- 스튜디오의 **스킨**에서 사막·야간·숲·네온으로 바꿔 보며, 어느 색 칸으로 나눠야 스킨이 예쁘게 바뀌는지 확인한다.

### 5-1. 정점 색 AO (선택, 추천)

홈·부품 사이·패널 테두리 같은 틈에 생기는 그림자(AO)를 **정점 색**으로 구워 넣는다. 게임은 정점 색을 기본 색에 곱하므로 **스킨을 바꿔도 그림자는 남는다**. UV·텍스처가 필요 없다.

1. 모든 메시를 고르고 **Object Data → Color Attributes → +** (도메인 *Vertex*, 이름 `Col`)
2. Render 엔진을 **Cycles** 로 → **Bake** 패널: Bake Type = **Ambient Occlusion**, Output = **Active Color Attribute**, Distance 0.02~0.05 (총 크기에 맞게)
3. **Bake** → 틈이 어두워진 것을 Vertex Paint 모드에서 확인
4. 내보낼 때 **Data → Mesh → Vertex Colors** 를 켠다 (`Use Vertex Color: Active`)

- 모든 물체에 굽는다 (일부만 있으면 스튜디오가 알려 준다). 너무 어두우면(평균 밝기 35% 미만) Distance 를 줄인다
- 저폴리라 그림자가 조금 덩어리져 보이는 것은 괜찮다 (이 스타일에 어울린다). 틈이 안 보이면 그 부분에 면을 조금 더 나눈다
- 스튜디오 모델 에디터의 "질감 → 정점 색 AO" 를 켜고 끄며 비교한다

## 6. 용량

| | 권장 | 최대 |
|---|---|---|
| 삼각형 수 | 6,000 | 12,000 |
| 파일 크기 | 300 KB | 800 KB |

- 원기둥(총열·총구)은 **8~12면**이면 충분하다.
- 안 보이는 면(부품끼리 맞닿은 안쪽)은 지운다.
- Decimate 로 줄이지 말자 (면이 지저분해진다). 처음부터 적은 면으로 만든다.

## 7. 내보내기

1. 모든 물체 선택 (A) → **Ctrl+A → All Transforms** (크기·회전 적용)
2. **File → Export → glTF 2.0**
   - Format: **glTF Binary (.glb)**
   - Include: 총만 있는 파일이면 그대로, 다른 게 섞여 있으면 **Selected Objects**. `socket_ads` 에 eye 를 넣었다면 **Custom Properties** 켜기
   - Transform: **+Y Up** 켜기 (기본값)
   - Data → Mesh: **Apply Modifiers** 켜기
   - Compression: **끄기** (게임이 압축 해제기를 쓰지 않는다)
   - Animation: 끄기 (재장전 모션을 넣었으면 **켜기**, Mode = **NLA Tracks** — 11 참고)
3. 파일 이름은 총 id 로: `vk12.glb` 처럼 **영문 소문자·숫자·_**

템플릿 스크립트의 `export_glb('/경로/vk12.glb')` 를 실행하면 위 설정으로 내보낸다.

## 8. 확인하고 저장하기

1. `npm run dev` → http://localhost:3002/studio/
2. .glb 를 화면에 끌어다 놓는다 (또는 총 모델 옆 **.glb 열기**)
3. 오른쪽 **규칙 검사**: ✕ 는 꼭 고친다 (저장이 잠긴다), ! 는 확인만.
4. 보기를 바꿔 가며 확인
   - **살펴보기**: 부착 지점이 제자리인지
   - **1인칭**: 게임에서 들었을 때 크기·위치가 괜찮은지
   - **정조준**: 빨간 점과 가늠쇠가 겹치는지
   - **파츠 달아 보기**: 조준경·소음기·앞 손잡이·탄창이 제자리에 붙는지
   - **스킨**: 색 칸이 잘 나뉘었는지
5. 위쪽에 총 id 를 넣고 **프로젝트에 저장** → `content/guns/<id>.glb` 가 생긴다.
6. 커밋해서 PR 로 올린다. Blender 원본(.blend)은 저장소 밖(또는 따로 정한 폴더)에 보관한다. 게임에는 .glb 만 들어간다.

## 9. 게임에 넣기 (데이터로 등록)

1. 프로젝트에 저장한 뒤 모델 에디터의 **데이터로 등록** → 이름과 **쓸 무기**를 고른다 (`content/models.json`).
   - 나중에 연결하려면: 데이터 에디터 → 무기 → 오른쪽 **모델** 에서 고르고 저장.
   - 새 무기로 쓰려면: 홈 → 무기 → **+ 새 무기** (모델을 꼭 골라야 만들어진다).
2. 그러면 게임이 **자동으로** 그 모델로 총을 그린다 — 1인칭, 다른 플레이어가 든 총, 무기고 벽 모두. 파츠도 부착 지점에 붙는다.
3. 모델을 불러오지 못하면 코드로 만든 총으로 대신 그린다 (게임이 멈추지 않는다).

## 10. 파츠 모델 (조준경 · 총구 장치 · 앞 손잡이)

파츠(`content/parts.json` 의 조준경·총열·손잡이)도 Blender 모델로 만든다. `content/parts/<파츠 id>.glb` 에 두고 `content/parts/index.json` 목록에 id 를 넣으면,
게임(`client/js/partmodels.js`)이 코드로 만든 모양 대신 이 모델을 총의 부착 지점에 붙인다. 파일이 없거나 못 불러오면 예전 코드 모양을 쓴다.

- 축·스타일·색 칸은 총과 같다 (+Y 앞, +Z 위, x = 0 가운데, 저폴리 + 색 칸 6개). 재질 값도 총과 같은 기준으로 입혀진다
- **원점 = 총에 붙는 곳.** 물체들은 빈 물체 `PART_<id>` 하나 아래에 묶는다

| 자리 | 원점 | 넣을 빈 물체 | 게임이 하는 일 |
|---|---|---|---|
| 조준경 (`reddot` `acog` …) | 레일 윗면 가운데 (총의 `socket_optic`) | `socket_sight` = 조준선 높이 (점·레티클 중심) | 정조준 높이 = 받침 + `socket_sight` 높이. 조준경을 통해 보이도록 창·통 안은 비운다 |
| 총구 장치 (`suppressor` `comp` `long`) | 총구 끝 (총의 `socket_muzzle`) | `socket_muzzle` = 새 총구 끝 | 총구 화염 위치가 그만큼 앞으로 간다 |
| 앞 손잡이 (`vertical` `angled` `stubby`) | 총열 덮개 아랫면 (총의 `socket_grip`), 아래(-Z)로 뻗는다 | 없음 | 그대로 붙인다 |

- 권총에 달 때는 0.72배로 줄어든다 (총의 `small`)
- 탄창(확장·신속)과 개머리판(경량·중량)은 따로 모델이 없다 — 총 모델의 `part_mag`·`part_stock` 크기를 바꾼다
- 원본: `모델링/parts_V.<n>.blend` (Text Editor 의 `build_parts.py`: `run_part("reddot")` 하나만 다시 만들기, `export_all("<content/parts 경로>")` 모두 내보내기)

## 11. 모션 클립 (재장전 등)

총 파일 안에서 **움직이는 부품과 왼손 목표**에 키를 잡아 클립으로 내보내면, 게임이 그 동작을 쓴다. 팔은 리깅하지 않는다 (게임의 1인칭 왼팔이 목표 점을 따라간다).

| 이름 | 종류 | 용도 |
|---|---|---|
| `part_mag`, `part_bolt` … | 움직이는 부품 (4 참고) | 위치·회전에 키 (크기는 키 잡지 않는다 — 확장 탄창 파츠가 쓴다) |
| `anim_hand_l` | 빈 물체 | **왼손 목표.** 첫 키(쉴 때)는 `socket_hand_l` 과 같은 자리. 게임의 왼팔이 (지금 위치 − 쉴 때 위치) 만큼 따라 움직인다 |

- 클립 이름 = **NLA 트랙 이름.** 물체마다 키를 잡은 뒤 NLA 트랙(이름 `reload`)으로 내려 두고, 내보낼 때 Animation Mode = **NLA Tracks** 로 하면 같은 이름끼리 클립 하나가 된다
- 첫 프레임과 마지막 프레임은 **쉴 때 자세**와 같아야 한다 (재장전이 끝나면 그대로 이어진다)
- 길이는 상관없다. 게임이 무기 데이터의 `reload` 시간에 맞춰 늘이거나 줄인다 (진행도 0~1 → 클립 처음~끝)
- 총 전체를 기울이는 동작은 넣지 않는다 — 게임 코드가 이미 한다 (겹쳐서 보인다)
- 지금 쓰는 클립: `reload` (탄창식 총). 클립이 없는 총은 예전처럼 코드가 탄창만 내렸다 올린다. 산탄총의 한 발씩 장전은 아직 코드 동작
- 예: `모델링/smg_hornet_V.4.blend` 의 Text Editor `anim_reload.py` (총을 다시 빌드해도 ▶ 실행하면 모션을 다시 입힌다)

## 게임에서의 크기 (2026-11-18)

총은 실제 크기(m)로 만든다. 게임은 모든 총·파츠를 `client/js/guns.js` 의 `WEAPON_SCALE` (현재 0.9) 배율로 줄여 그린다 — 캐릭터(키 1.60 m)에 맞춘 값.
부착 지점(socket_*)도 같은 배율로 줄어든 자리로 쓰이므로 모델을 따로 줄일 필요는 없다 (모델 안에서 크기를 바꾸면 규칙 검사가 경고한다).
