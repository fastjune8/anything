# 모델 에디터 사용법 (튜토리얼)

FRONTIER Studio 의 **모델 에디터**는 Blender 에서 만든 모델(.glb)을 게임에 넣기 전에 확인하는 곳이다.
화면에서 직접 눌러 보며 따라 하는 **1분 안내**는 홈 → 모델 → **튜토리얼** 버튼 (또는 ? → "모델 에디터 튜토리얼").

## 0. 켜기

```bash
cd anything/games/frontline
git pull
npm run dev          # → 브라우저에서 http://localhost:3002/studio/
```

## 1. 모델 에디터에는 세 가지가 있다

홈 → **모델** 에서 위쪽 버튼으로 고른다. 카드를 **두 번** 누르면 열린다.

| 종류 | 무엇을 확인하나 | 여는 법 |
|---|---|---|
| **총 · 근접** | 규칙 검사(부착 지점 …), 1인칭, 정조준, 파츠, 스킨 | 카드 두 번 / `.glb` 를 화면에 끌어다 놓기 |
| **캐릭터** | 뼈·웨이트·무기 쥐기·애니메이션, 규칙 검사 | 카드 두 번 |
| **의상** | 옷 입히기·벗기기·바꾸기, 몸 가려짐, 1인칭, 탈부착 검사 | "의상 입혀 보기" 버튼 / 의상 카드 두 번 |

화면 구성은 모두 같다: **위 = 버튼 · 왼쪽 = 도구 상자 · 가운데 = 화면 · 오른쪽 = 속성(검사 결과)**.
총·캐릭터의 도구 상자는 기능이 많아서 위쪽 **탭**으로 나뉘어 있다 (한 번에 한 묶음만 보인다).
찾는 기능이 안 보이면 다른 탭을 눌러 본다.

| 화면 | 탭 |
|---|---|
| 총 | 보기 / 파츠 · 스킨 / 모션 / 질감 |
| 캐릭터 | 보기 / 뼈 / 무기 · 동작 |
| 의상 | (탭 없음 — 위에서 아래로 ① ② ③ 순서) |

## 2. 의상 — 옷 탈부착 · 교체 해 보기

게임과 **같은 몸, 같은 옷 코드**로 보여 주므로, 여기서 되면 게임에서도 된다. 저장할 것은 없다.

1. 홈 → 모델 → **의상** → **의상 입혀 보기**. (의상 카드를 두 번 누르면 그 옷을 입은 채로 열린다.)
2. **① 옷 고르기** — 칸(머리 장비 · 머리카락 · 상의 · 하의 · 장갑 · 신발 · 등 · 가방)마다 목록에서 옷을 고르면 **바로 입혀진다**.
   - 이미 입고 있으면 → **교체** (원래 옷은 벗겨지고 새 옷만 남는다)
   - `(벗음)` 또는 `×` → 그 칸만 **벗기**. 옷 밑의 몸이 다시 보인다.
3. **② 한 번에** — `기본 복장` (게임 기본 옷) / `전부 벗기` (맨몸).
4. **보기** — 정면·뒷면·옆·3/4·상체·하체·머리·발. 화면 오른쪽 아래의 작은 창은 **게임 1인칭 카메라** (팔·장갑이 제대로 보이는지). 자세 목록으로 달리기·점프 같은 동작에서도 확인한다.
5. **색 · 피부** — 팔레트, 피부색, 팀 색(아군/적군).
6. 오른쪽 **입고 있는 옷** — 칸마다 입은 옷, 입혀졌는지, 1인칭 모델이 있는지, 가려진 몸 영역. 못 입혀지면 이유(다른 옷이 막음 / 뼈 이름 안 맞음)가 적힌다.

### 탈부착 · 교체 검사

오른쪽 **검사 실행**을 누르면 실제로 돌려 보고 ✓ / ✕ 로 알려 준다 (끝나면 지금 입은 옷으로 돌아온다).

| 항목 | 확인하는 것 |
|---|---|
| 전부 벗기 | 옷 메시가 전부 사라지고 몸 가리기가 0 (3인칭·1인칭) |
| 칸마다 입기 → 벗기 | 입으면 메시와 몸 가리기가 생기고, 벗으면 사라지고 몸이 복원 |
| 같은 칸 A ↔ B 교체 | A 가 사라지고 B 만 남고, 다른 칸의 옷은 그대로 |
| 빠른 A → B → A | 마지막 요청(A)이 입혀진다 |
| 120번 갈아입기 | GPU 형상·장면 노드가 늘지 않는다 (누수 없음) |

**`!` 건너뜀** = 확인하지 못한 항목이다. 지금은 칸마다 옷이 1벌뿐이라 "교체"는 **건너뛴다**.
새 옷이 생기면 다시 검사하면 자동으로 포함된다.

## 3. 새 의상이 생겼을 때 (나중에 추가되는 옷)

의상은 `content/cosmetics.json` 의 `items` 에 한 줄로 등록한다 (칸 설명: `docs/CHARACTER_CUSTOMIZATION.md` §3, 만드는 법: §4).

- **등록한 옷** → 의상 화면에서 **새 의상 찾기** 를 누르면 (스튜디오를 껐다 켜지 않아도) 그 칸의 목록에 나온다. 고르면 바로 교체되고, **검사 실행**에 같은 칸 교체가 포함된다.
- **아직 등록 전인 `.glb`** → 의상 화면에 **끌어다 놓거나** ③ `의상 .glb 입혀 보기…` 로 고른 칸에 **임시로** 입혀 본다 (저장되지 않고, 1인칭 모델은 없다). 몸·재질 규칙이 안 맞으면 이유가 콘솔에 나온다.
  - 임시 입기로도 **검사 실행**이 돌아간다 → 정식 등록 전에 교체가 되는지 미리 확인할 수 있다.

## 4. 총 모델 (요약)

1. Blender 에서 `tools/blender/frontier_gun_template.py` 로 준비 → `.glb` 내보내기 (규칙: `docs/GUN_MODELING.md`).
2. 스튜디오 화면에 `.glb` 를 끌어다 놓는다 → 오른쪽 **규칙 검사**의 ✕ 를 모두 고친다.
3. **보기** 탭에서 살펴보기 / 1인칭 / 정조준 (빨간 점에 가늠쇠가 겹치면 정상).
4. 총 id 를 넣고 **프로젝트에 저장** → 통과하면 **데이터로 등록** 에서 쓸 무기를 고른다.

## 5. 캐릭터 (요약)

리깅된 `.glb` 를 열면 규칙 검사 (`docs/CHARACTER_MODELING.md`). **뼈** 탭에서 관절을 눌러 돌려 보며 몸이 자연스럽게 휘는지, **무기 · 동작** 탭에서 무기 쥐기와 애니메이션을 본다.

## 막혔을 때

| 증상 | 확인 |
|---|---|
| 의상 화면이 안 열린다 | 콘솔(아래 막대) 확인. `content/characters/` 에 몸 파일이 있어야 한다 |
| 옷이 "입혀지지 않음" | 옷 `.glb` 의 뼈 이름이 몸과 같은지, 재질 이름이 색 칸(`fabric` 등)인지 |
| 옷이 "막힘" | 다른 옷의 `occupies` / `blocks` 규칙 (예: 헬멧이 머리 장비 칸을 막음) |
| 1인칭에서 맨팔이 보인다 | 팔·가슴을 가리는 옷은 `fp` 모델이 필요 |
| 도구가 안 보인다 | 왼쪽 도구 상자 위쪽 **탭**을 눌러 본다 |
