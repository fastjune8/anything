# FRONTLINE DUEL

웹 브라우저에서 즐기는 FPS 자유 대전. 한 방에 최대 8명이 겨루고, 사람이 모자라면 봇이 채워서 혼자 들어와도 바로 시작된다.
20킬을 먼저 달성하거나 5분이 지나면 최다 킬이 승리하고, 10초 뒤 새 경기가 자동으로 시작된다.

## 빠르게 해 보기

```bash
npm install
npm run dev          # http://localhost:3002
```
