# FRONTLINE DUEL

웹 브라우저에서 즐기는 FPS. 로비에서 모드를 고르면 바로 시작되고, 사람이 모자라면 봇이 채운다.

| 모드 | 내용 | 맵 |
|---|---|---|
| 개인 데스매치 | 최대 8명, 모두가 적. 20킬 선승 또는 5분 뒤 최다 킬 | 전선 |
| 팀 데스매치 5 대 5 | 두 팀, 아군 사격 무효. 팀 합계 50킬 선승 또는 5분 뒤 점수가 높은 팀 | 창고 |

## 빠르게 해 보기

```bash
npm install
npm run dev          # http://localhost:3002
```
