# FRONTIER

> **기준 문서:** 게임 기획의 최상위 기준은 [`docs/GAME_DESIGN.md`](docs/GAME_DESIGN.md) 이다. 이 문서·코드·다른 docs 와 내용이 다르면 기획서가 우선한다.

무기와 무기 스킬 조합으로 싸우는 웹 하이퍼 FPS. 로비에서 모드를 고르면(파티도 함께) 바로 시작되고, 사람이 모자라면 봇이 채운다.
엔진: 서버 권한 60Hz 시뮬레이션 + 브라우저 예측 + 스냅샷 보간 + 되감기 판정 ([ENGINE.md](docs/ENGINE.md)).

| 모드 | 내용 | 맵 |
|---|---|---|
| **점령전 5 대 5** (대표 모드) | 거점 A·B·C 를 점령해 점수를 쌓는다. 거점 하나가 초당 0.25점, 100점 선승 / 10분, 동점이면 연장전 | 골목극장 |
| 팀 데스매치 5 대 5 | 팀 합계 50킬 선승 / 8분 | 골목극장 |
| 개인전 | 최대 8명, 20킬 선승 / 8분 | 골목극장 |

맵: 골목극장(기본) · 아스테르 항만 · 교차 동력실 — 레벨 디자인 기획서 v2.0 블록아웃 (`tools/maps/gen_v2_maps.mjs`). 다른 맵은 커스텀 방에서 고른다. 예전 대표 맵 전초기지는 목록 뒤에 보관.

무기 8종(돌격소총·SMG·산탄총·저격·근접·리볼버·아킴보·LMG) + 특수 무기 듀얼 쿠나이, 무기마다 고르는 스킬, 계정 레벨·전적, 친구·파티·채팅·커스텀 방(비밀번호).

## 빠르게 해 보기

```bash
npm install
npm run dev          # http://localhost:3002
```
**FRONTIER Studio** (맵·총 모델·무기·파츠·모드 편집): 개발 서버에서 http://localhost:3002/studio/ (라이브에는 없다) — [사용법](docs/STUDIO.md)

## 조작

| | |
|---|---|
| 이동 / 달리기 / 점프 | W A S D / Shift / Space (낮은 구조물 앞에서는 넘어가기·오르기) |
| 슬라이딩 / 앉기 | 달리다가 C (또는 Ctrl) / 멈춰서 C |
| 사격 / 정조준 | 좌클릭 / 우클릭 또는 T |
| 재장전 / 무기 교체 | R / 1·2, 휠 |
| 스킬 | Q = 주무기 자리 스킬, E = 보조무기 자리 스킬 (로비에서 고른다) |
| 듀얼 쿠나이 | 좌클릭 왼손 · 우클릭 오른손 (던지기/회수) · R 둘 다 회수 · X 기동/설치 모드 · F 핀 노드 · 스킬 키 = 모드 능력 ([설명](docs/weapons/DUAL_KUNAI.md)) |
| 전술 지도 / 점수판 / 3인칭 | M / Tab / V |
| 채팅 | Enter (경기 중 = 방 전체, 로비 = 로비·파티) |
