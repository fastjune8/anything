# FRONTIER

다양한 무기의 스킬을 조합해서 싸우는 웹 하이퍼 FPS. 로비에서 모드를 고르면 바로 시작되고, 사람이 모자라면 봇이 채운다.

| 모드 | 내용 | 맵 |
|---|---|---|
| **점령전 5 대 5** (대표 모드) | 거점 하나를 차지하고 지킨다. 거점을 가진 팀이 1초에 1점(교전 중엔 멈춤), 100점 선승 | 창고 |
| 개인 데스매치 | 최대 8명, 모두가 적. 20킬 선승 또는 5분 뒤 최다 킬 | 전선 |
| 팀 데스매치 5 대 5 | 두 팀, 아군 사격 무효. 팀 합계 50킬 선승 또는 5분 뒤 점수가 높은 팀 | 창고 |

## 빠르게 해 보기

```bash
npm install
npm run dev          # http://localhost:3002
```
**FRONTIER Studio** (맵·총 모델·무기·파츠·모드 편집): 개발 서버에서 http://localhost:3002/studio/ (라이브에는 없다) — [사용법](docs/STUDIO.md)

## 조작

| | |
|---|---|
| 이동 / 달리기 / 앉기 / 점프 | W A S D / Shift / C / Space |
| 넘어가기 · 오르기 | 창문·모래주머니·상자 같은 낮은 구조물 앞에서 Space |
| 스킬 | Q(1번 = 주무기에 고른 스킬) / E(2번 = 보조무기에 고른 스킬). 무기고에서 무기마다 고른다 |
| 사격 / 정조준 | 좌클릭 / 우클릭 또는 T |
| 재장전 / 무기 교체 | R / 1·2, 휠 (들고 갈 무기 2개와 파츠는 로비의 무기고에서) |
| 채팅 | Enter (전송 Enter, 취소 Esc) |
